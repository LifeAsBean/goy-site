# GOY — The Internet Is Cooked

A mascot-led internet-culture landing page for GOY and Gloop.

## Project status

Pre-launch concept site. No mainnet token has been deployed, no contract address is published, and no token sale is open.

## Local preview

Open `index.html` in a browser.

## Publishing

Enable GitHub Pages in **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Safety and transparency

Never publish an unverified contract address. Before any mainnet launch, finalize supply, distribution, creator holdings, authority settings, liquidity arrangements, and legal review. No return, liquidity, utility, or exchange listing is promised.
